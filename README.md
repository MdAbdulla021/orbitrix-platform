# OrbitriX

OrbitriX is a Student Lifecycle Platform for Maatram, following one person
from application to student to alumnus.

Only fake data is used in this project.

## Requirements

- Node.js
- Git
- Docker Desktop
- About 4 GB of free RAM

## Setup

```powershell
git clone https://github.com/MdAbdulla021/orbitrix-platform.git
cd orbitrix-platform
npm.cmd install
npx.cmd supabase start
npx.cmd supabase db reset
```

Read the [project plan](docs/PLAN.md) for the build phases and working rules.

## How to contribute

- Use one branch per task.
- Keep commits small and focused.
- Open a pull request for review.
- Never push straight to `main`.
